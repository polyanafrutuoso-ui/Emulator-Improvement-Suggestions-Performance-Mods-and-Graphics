RAM Optimization Improvements

1. Adaptive Memory Management: Automatically adjust memory usage according to available RAM.
2. Smart Texture Cache: Remove unused textures from memory automatically.
3. GPU Texture Compression: Reduce graphics memory consumption.
4. On-Demand Asset Loading: Load only the game resources currently needed.
5. Automatic Resource Cleanup: Release unused resources when leaving game areas.
6. Mipmap Optimization: Use smaller textures when high resolution is unnecessary.
7. Memory Deduplication: Avoid storing duplicate textures and buffers.
8. Buffer Pooling: Reuse allocated memory instead of constantly creating new buffers.
9. Lazy Memory Allocation: Allocate memory only when game resources are actually needed.
10. Streaming Decompression: Decompress game assets in small chunks to reduce temporary memory usage.
11. Background Loading Limits: Prevent background tasks from consuming too much RAM.
12. Render Target Optimization: Reuse graphical buffers instead of allocating new ones repeatedly.
13. Shader Cache Memory Management: Keep only frequently used shader data in RAM.
14. Memory Fragmentation Reduction: Organize memory allocations to reduce wasted space.
15. Automatic Memory Pressure Handling: Detect high memory usage and automatically release unnecessary resources before the emulator reaches its limit.
    The goal is to significantly reduce RAM consumption, prevent memory overload and make games more stable on Xbox Series S and Series X in Developer Mode.
